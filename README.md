# 🎨 Image Editor Pro

A modern web-based image editor built with **HTML, CSS, and JavaScript** using the **Canvas API**. This application allows users to upload images, apply real-time filters, zoom and pan images, compare original and edited versions, download edited images, and remove backgrounds using AI.

---

## 🚀 Features

### 🖼 Image Upload

* Upload images directly from your device
* Instant image preview on canvas

### 🎚 Real-Time Filters

* Brightness
* Contrast
* Saturation
* Hue Rotation
* Grayscale
* Sepia
* Invert
* Blur
* Opacity

### 🔍 Zoom & Pan

* Mouse wheel zoom
* Drag and move image
* Smooth canvas interaction

### 🔄 Before / After Preview

* Compare original image with edited version
* One-click toggle

### ♻️ Reset Functionality

* Restore all filters to default values
* Reset image to original state

### 🤖 AI Background Removal

* Remove image backgrounds with one click
* Powered by Remove.bg API
* Transparent PNG output

### 💾 Download Edited Image

* Export edited image as PNG
* High-quality image output

## 🔑 API Setup

This project uses Remove.bg API for AI background removal.

1. Create an account on Remove.bg
2. Generate an API key
3. Add your API key in the JavaScript file

```javascript
headers: {
  "X-Api-Key": "*******************"
}
```

> Never expose your API key publicly in production applications.
